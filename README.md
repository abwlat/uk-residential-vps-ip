## 住宅IP和数据中心IP到底差在哪

数据中心IP属于机房批量分配的地址段，whois查询会显示托管公司（如Hetzner、OVH），很多平台的反欺诈系统会直接标记这类IP。住宅IP则来自真实的家庭宽带运营商，在IP数据库里标记为"住宅"或"ISP"类型。

"住宅""原生""ISP"这几个词在不同数据库里的识别结果并不完全统一。有些工具显示住宅，有些可能只标成"ISP"或"broadband"。
